i.hyper.poppy

Opium poppy (Papaver somniferum) detection — max-abundance map from built-in multi-stage spectral reference match in a hyperspectral 3D raster

Synopsis

i.hyper.poppy input=name output=name [growth_stage=string] [poppy_db=name]
              [method=string[,string,...]] [fusion_mode=string]
              [agreement_threshold=float] [output_prefix=string]
              [resample=string] [normalize=string] [shift_window=integer]
              [min_wavelength=float] [max_wavelength=float]
              [coordinates=east,north]
              [-n] [-i] [-v] [-c] [-p] [-z]

Description

i.hyper.poppy finds the pixels in a hyperspectral 3D raster that most closely match Papaver somniferum (opium poppy) using built-in canopy-level and leaf-level reference spectra compiled from peer-reviewed literature.

The module embeds four reference spectra:

  • before_flowering — vegetative rosette canopy (June, NW China, 65 cm height); ASD FieldSpec Pro 350–2500 nm. Optimal discrimination bands: 438, 528, 736, 754, 1207 nm (JM ≈ 1.20).
  • flowering — white-petal canopy (July, NW China, 125 cm height); elevated visible reflectance due to large white petals. Optimal bands: 405, 424, 524, 760, 1974 nm (JM ≈ 1.22).
  • harvesting — mature capsules + senescing leaves (mid-July, NW China, 130 cm height). Optimal bands: 468, 726, 746, 982, 1220, 1689 nm (JM ≈ 1.21).
  • leaf_healthy — asymptomatic leaf-level spectrum (350–800 nm) measured with Li-Cor 1800-12 integrating sphere.

For each pixel the similarity score of all selected spectra is computed and the maximum is reported in the output raster. The optional output_prefix= parameter writes per-stage similarity maps alongside the main output.
